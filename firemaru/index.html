Features

Powerful Firestore Manager

ドキュメント閲覧・編集・削除・作成から、差分確認、Filter、JS Query、CSV / JSON の入出力まで対応。

  • TABLE / TREE / JSON ビュー

Storage Explorer

ツリー表示、プレビュー、フォルダ作成、複数アップロード、削除まで、Storageをファイルブラウザのように扱えます。

  • エクスプローラ形式のツリー表示

  • フォルダ作成と複数ファイルアップロード

Authentication Manager

Firebase Authユーザーの一覧・検索・詳細確認・編集・無効化・CSV / JSON出力をまとめて提供。

  • メール / UID / 表示名で検索
  • emailVerified / disabled / 電話番号編集
  • カスタムクレーム編集
  • firebase CLI 互換のエクスポート

Cloud Functions Logs Viewer

関数一覧、ログ表示、重要度フィルター、検索、自動更新で、障害調査や運用確認を効率化します。

  • v1 / v2 Functions を統合表示

FAQ

導入前によくある質問

Firemaru は Firebase Console の代替ですか？

完全な置き換えではなく、日常運用を大幅に効率化する補完ツールです。Consoleで行っていた多くの確認・編集作業を、より見やすく速く行えます。

サービスアカウントキーの扱いは安全ですか？

ローカル保存前提で、暗号化を前提にした構成です。公開サーバで運用するSaaSではなく、デスクトップアプリとしての安全性を重視しています。

どのOSに対応していますか？

このLPでは Mac / Windows を想定しています。必要なら Linux 対応案内も簡単に追加できます。

このHTMLはそのまま公開できますか？

はい。リンク先やスクリーンショット、価格を差し替えれば、そのまま静的サイトとして公開できます。
