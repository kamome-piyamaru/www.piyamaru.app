Problem

Firebaseコンソール、こんなことになっていませんか。

タブが増え続ける

Firestore、Auth、Storage…サービスごとにタブを開き、気づけばブラウザはFirebaseだらけ。目当ての画面を探すだけで時間が溶けていきます。

プロジェクト切替が面倒

本番・ステージング・開発。複数プロジェクトを行き来するたびに読み込みを待ち、「今どっちの環境だっけ？」と冷や汗をかく日々。

データ確認に手間がかかる

Firestoreのドキュメントを1件ずつクリックして開く作業。ちょっと中身を確認したいだけなのに、コンソールでは一覧性が足りません。

Solution

firemaruなら、ぜんぶひとつの画面で。

ブラウザを開かず、デスクトップアプリとしてFirebaseを操作。サービスアカウントキーを登録するだけで、すぐに使い始められます。

01

ネイティブアプリの速さ

デスクトップアプリだから起動も画面遷移も軽快。コンソールの読み込みを待つ時間がなくなります。

02

複数プロジェクトを一元管理

本番・開発などの複数プロジェクトを登録して、ワンクリックで切り替え。環境の取り違えも防ぎやすくなります。

03

データが一覧で見える

Firestoreのコレクションをテーブル表示。全体を眺めながら確認・編集できるので、データ調査がはかどります。

Features

主な機能

🗂

Firestore管理 /firestore

コレクション・ドキュメントの閲覧、検索、追加、編集、削除をGUIで。テーブル表示で全体を把握しながら操作できます。

👤

Authentication管理 /auth

ユーザーの一覧表示・検索・追加・無効化などをアプリ内で完結。ユーザーサポート時の確認作業がスムーズになります。

📦

Storage管理 /storage

バケット内のファイルをエクスプローラー感覚でブラウズ。アップロード・ダウンロード・削除もドラッグ操作で直感的に。

⚡️

Cloud Functions管理 /functions

デプロイ済み関数の一覧と状態をひと目で確認。どの関数が動いているか、コンソールを開かずに把握できます。
