# スクリーンショット撮影ガイド

撮影したファイルは **`manual/img/ja/`** に配置してください。  
英語・ドイツ語版が日本語と同じ画面でよければ `img/en/`・`img/de/` にも同じファイルをコピーすればOKです。

## 撮影のコツ

- **ショートカット**: `⌘+Shift+4` → Spaceキー → アプリウィンドウをクリックでウィンドウ全体をキャプチャ
- **サイズ**: 横幅 1200〜1440px 程度が見やすい
- **テーマ**: Dark Navy（デフォルト）で統一推奨
- **個人情報**: プロジェクトIDやメールアドレスが映る場合はモザイク不要（開発用データでOK）

## 配置場所

```
manual/
  img/
    ja/    ← 日本語版（まずここに入れる）
      fig0-1.png
      fig1-1.png
      fig1-2.png
      fig2-1.png
      fig2-2.png
      fig3-1.png
      fig4-1.png
      fig5-1.png
      fig6-1.png
      fig7-1.png
    en/    ← 英語版（jaと同じでもOK）
    de/    ← ドイツ語版（jaと同じでもOK）
```

画像を置いたらブラウザで `manual/index.html` を開くと自動で表示されます。
